# 案件フォルダを作る

スクリプトの場所：`${CLAUDE_PLUGIN_ROOT}/scripts`（変数が展開されていなければ、この SKILL.md から見て `../../scripts`）。以下 `$S` と書く。

## 1. 聞くこと（会話で分からないものだけ）
- クライアント名（フォルダ名になる。正式名か略称かを確認）
- 決算期末日（例 2026-03-31）
- 種別：法定監査／任意監査／内部監査／決算チェック
- 案件フォルダを並べる親フォルダ（いま開いているフォルダが `監査案件` のような親なら、それを使う）
- 前期の案件フォルダがあるか

## 2. 作る
今日の日付を `date +%F` で取り、次を実行する。
```bash
python3 $S/engagement.py new --root "<親フォルダ>" --client "<クライアント名>" \
  --period-end <YYYY-MM-DD> --engagement-type "<種別>" --today <今日> [--prior "<前期フォルダ>"]
```
同名フォルダがあると止まる。上書きせず、人に確認する。

## 3. 伝えること
- 作ったフォルダの場所
- 次にやること：
  1. このフォルダを Cowork で開き直す（他社のフォルダと同じセッションで開かない）
  2. `00_案件情報/engagement.json` の期間・担当・依頼先を埋める（会話で教えてもらえれば代わりに書く）
  3. 試算表・仕訳帳など最初の資料を渡してもらい、`/tadori:intake` で取り込む
- 前期から引き継いだ項目があれば、計画承認のときに見直すよう伝える

## フォルダ構成
```
<クライアント>_<YYYY-MM>期/
├─ 00_案件情報/   engagement.json、plan.json、前期引継ぎ.md
├─ 01_受領資料/   原本。編集・削除禁止（hooks で止まる）
├─ 02_正規化データ/
├─ 03_調書/       領域ごとの調書 JSON とレビュー結果
├─ 04_依頼管理/   pbc.jsonl、依頼トラッカー.xlsx、送信ログ
├─ 05_成果物/     人に渡す最終版だけ
└─ 06_ログ/       受領台帳、ツール呼出ログ、承認記録
```
