# 仕訳テスト（JE-）

## JE-01 母集団の網羅性
- 仕訳帳の全件が試算表と一致することを `recon.py` で確かめる。不一致なら以降に進まない
- 期中の仕訳件数・金額を月別に集計し（`monthly.py`）、空白期間や急増がないかを見る
- 伝票の並びを母集団全件で調べる。欠番、番号順での計上日・入力日時の逆転、伝票内の入力日時のずれ、入力の遅れを数え、例外が一部の番号帯や入力者に偏っていないかを見る
  ```bash
  python3 $S/je_sequence.py --gl 02_正規化データ/仕訳帳.csv --lag-days 7
  ```
  入力日時が作成日時か最終更新日時かで意味が変わる。会計システムの仕様を確かめるまでは補助情報として扱う

## JE-02 条件抽出
```bash
python3 $S/je_filter.py --gl 02_正規化データ/仕訳帳.csv --period-end <期末日> \
  --close-date <決算確定日> --round-unit 1000000 --holidays <engagement.json の holidays>
```
- 抽出条件は plan.json の `je_test` を使う
- 当たった条件が多い仕訳から順に見る。1件ずつ、摘要・相手科目・入力者・承認・裏付け資料を確認する

## JE-03 期末・決算整理仕訳
- 期末日前後と決算確定後の入力（`period_end`、`post_close`）は全件見る
- 手入力の決算整理仕訳のうち、手続上の重要性の 10% を超えるものは裏付け資料を依頼する

## JE-04 結論
- 不正の兆候がある仕訳は、調書の `escalations` に書き、資料依頼のキューには入れない（依頼内容が手の内を見せるため）
- 抽出条件、件数、確認した件数、例外を記録する
