# 継続企業・後発事象（GC- / SE-）

## GC-01 継続企業の前提に関する兆候
- 確かめる指標：営業損失・営業キャッシュ・フローのマイナスの継続、債務超過、借入金の返済条件・財務制限条項への抵触、重要な取引先の喪失
- 数字は試算表と資金繰り表から計算する
- 兆候がある場合、経営者の対応策の実行可能性は人の判断に上げる

## SE-01 後発事象
- 期末日から報告日までの取締役会・株主総会の議事録、稟議、期末後の月次試算表、大口の入出金を確認する
- 期末時点の状況を示す事象（修正後発事象）と、期末後に生じた事象（開示後発事象）を区別して記録する
- 報告日が近づいたら、経営者への質問（人が行う）の記録を受領資料として取り込み、更新する

## 依頼する資料の例
資金繰り表（向こう12か月）、借入契約書と財務制限条項の判定資料、期末後の議事録、期末後の月次試算表
