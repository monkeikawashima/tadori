# リスク評価（RA-）

## RA-01 分析的手続（計画段階）
- 目的：増減の大きい科目と、説明のつかない変動を見つける
- データ：当期・前期の試算表（月次があれば月次）
- 手順：前期比（金額と率）、月次推移、売上総利益率・回転期間（売掛金、棚卸資産、買掛金）を Python で計算する。前期比で手続上の重要性を超える増減、または率が ±20% を超える科目を一覧にする
- 出力：plan.json の `risk_assessment` に、科目・増減・考えられる要因・リスクの水準

## RA-02 重要性の案
- ベンチマークと率の目安（案として出し、決めるのは人）
  - 税引前利益の 5%（利益が安定している営利企業）
  - 売上高の 0.5〜1%、総資産の 1〜2%（利益が小さい・変動が大きい場合）
  - 純資産の 1〜2%
- 手続上の重要性：全体の 50〜75%（初年度や前期に指摘が多い場合は低め）
- 明らかに僅少な金額：全体の 5% 程度
- 前期の値があれば並べる

## RA-03 不正リスク
- 収益認識と経営者による内部統制の無効化は、反証がない限り常に特別なリスクとして扱う
- 前期引継ぎ、業績目標・借入の財務制限条項、経営者の交代、新規の大口取引先を確認する

## RA-04 領域の切り方
- 1領域 = 勘定科目（またはその束）× アサーション
- 特別なリスクは独立した領域にする（例：売上の期間帰属を売上の他のアサーションと分ける）
