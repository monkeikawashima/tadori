# 成果物の形式と置き場所

## 形式の選び方
| 中身 | 形式 | 理由 |
|---|---|---|
| 明細・突合・サンプリング結果・未修正虚偽表示一覧・依頼トラッカー・調書一式 | Excel | 査閲者が数式をたどって再計算できるようにする。合計は値でなく数式で入れる |
| 監査計画書・査閲メモ・マネジメントレター・意見書ドラフト | Word | 人の査閲を変更履歴で受ける |
| 確定版、クライアントへの提出物 | PDF | 改変を防ぐ。元の Word / Excel と対で保存する |

迷ったら「受け取った人が次に何をするか」で決める。数字を検算するなら Excel、文章を直すなら Word、受け取って保管するだけなら PDF。

作るときは Claude 標準の Excel・Word・PDF 作成機能（xlsx / docx / pdf スキル）を使う。事務所の書式が `templates/firm/` にあればそれを土台にする（このリポジトリには入れていない。各事務所で置く）。

## ファイル名
```
<クライアント>_<YYYY-MM>期_<書類名>_v<版>_<YYYYMMDD>.<拡張子>
例：ABC商事_2026-03期_未修正虚偽表示一覧_v3_20261027.xlsx
```
- 版は同じ書類名の既存ファイルの最大版＋1。古い版は消さない
- 確定版の PDF は書類名の後ろに `_確定` を付ける

## 置き場所
- `05_成果物/`：人に渡す最終版だけ
- 作業途中の表や中間ファイルは `03_調書/` か `02_正規化データ/`
- 他の案件フォルダには書かない（hooks で止まる）

## 中身のルール
- 金額は円単位、3桁区切り、負数は赤字＋マイナス
- 調書から証拠への参照は evidence_id を書き、可能なら 01_受領資料 のファイルへハイパーリンクを張る
- AI が作った成果物であることを査閲メモの冒頭に1行書く。結論や意見を確定した表現にしない（「〜と判断した」ではなく「〜と評価した。査閲者の確認が必要」）
