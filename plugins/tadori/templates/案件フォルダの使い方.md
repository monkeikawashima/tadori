# この案件フォルダの使い方

Cowork でこのフォルダだけを開いて作業します。他のクライアントのフォルダを同じ作業で開かないでください。

| フォルダ | 入れるもの | 触ってよいか |
|---|---|---|
| 00_案件情報 | 案件の設定（engagement.json）、監査計画（plan.json）、前期からの引継ぎ | 計画承認後は変更不可 |
| 01_受領資料 | クライアントから受け取った原本 | 追加は取込コマンドだけ。編集・削除不可 |
| 02_正規化データ | 原本を表に直したもの | AI が作る |
| 03_調書 | 領域ごとの調書とレビュー結果 | AI が作る。人は読む |
| 04_依頼管理 | 依頼トラッカー.xlsx、送信ログ | 途中経過はトラッカーで確認 |
| 05_成果物 | 人に渡す最終版 | 最終査閲はここから |
| 06_ログ | 受領台帳、作業ログ、承認記録 | 証跡。消さない |

## 流れ
1. `/tadori:intake` 試算表・仕訳帳などを取り込む
2. `/tadori:plan` 計画のドラフト → **あなたが承認**
3. `/tadori:run` 手続とレビューを回す。資料が足りなければ依頼キューへ
4. `/tadori:request-mail` 依頼メール（最初は下書き）
5. 資料が届いたら `/tadori:intake`（定期実行にもできる：`/tadori:schedule`）
6. `/tadori:finalize` 横断チェックと査閲資料 → **あなたが最終査閲**
