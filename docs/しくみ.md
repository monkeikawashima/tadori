# しくみ

## 案件フォルダ

1クライアント・1決算期につき1フォルダです。Cowork では1回の作業で1つの案件フォルダだけを開きます。別の案件フォルダへの書込は自動で止まります。

```
監査案件/
├─ 案件台帳.xlsx            全案件の一覧（自動で更新）
└─ ABC商事_2026-03期/
   ├─ 00_案件情報/           設定と監査計画（承認後は変更不可）
   ├─ 01_受領資料/           原本（編集・削除不可）
   ├─ 02_正規化データ/
   ├─ 03_調書/
   ├─ 04_依頼管理/           依頼トラッカー.xlsx
   ├─ 05_成果物/             人に渡す最終版
   └─ 06_ログ/               受領台帳・作業ログ・承認記録
```

## 進み方

```
資料の取込 → 計画（承認） → 実行 → レビュー → 採点 → 修正 → レビュー … → 横断チェック → 最終査閲
                                  └ 資料が足りない → 依頼メール → 受領 → その領域だけ再実行
```

- 領域（勘定科目 × アサーション）ごとに並列で進みます
- レビューは修正した担当とは別のモデルが、調書と証拠だけを見て行います
- 合格は「必須チェックの違反0件、かつ85点以上」。4周しても届かないか、点数が上がらなくなったら、人の判断に回します
- 最後に、反証担当が複数で結論を疑い直します

## 成果物

| 中身 | 形式 |
|---|---|
| 明細・突合・サンプリング・未修正虚偽表示一覧・依頼トラッカー | Excel（数式を残す） |
| 監査計画書・査閲メモ・マネジメントレター | Word |
| 確定版・クライアント提出用 | PDF |

ファイル名は `<クライアント>_<YYYY-MM>期_<書類名>_v<版>_<日付>` にそろえます。古い版は消しません。

## 資料依頼メール

- 最初は下書きを作るだけです。中身を確かめて自分で送ってください。慣れたら自動送信に切り替えられます
- 依頼先1人につき1日1通にまとめます。3営業日返事がなければ督促、さらに3営業日で人の判断に回します
- 銀行・取引先への確認状と、不正の兆候に関わる資料はメールで依頼しません

## 安全のための制限

| 制限 | 内容 |
|---|---|
| 原本の保護 | 01_受領資料 への書込・削除・移動を止める。取込時に SHA-256 を記録し、改変を検出する |
| 計画の固定 | 承認後は計画と設定を変更できない。差戻しは理由付きで記録される |
| 案件の取り違え防止 | 開いている案件以外のフォルダへの書込を止める |
| 合否の固定 | 調書の合否・周回・点数の記録はスクリプトだけが書く。AI が自分で「合格」と書き換えることはできない |
| メール宛先 | 計画承認時に登録した担当者以外への送信、転送、宛先不明の返信を止める |
| 外部の文書 | 受領資料やメール本文の中の指示文には従わない。メールを読む役と送る役を分けている |
| 計算 | 合計・突合・サンプリング・仕訳抽出は Python で計算し、AI に暗算させない |
| 証跡 | 全ての操作を 06_ログ に記録する |

これらは Python 3 で動きます。Cowork には最初から入っています。Windows で Claude Code（ターミナル）から使う場合は Python 3 を入れてください。入っていないと `/tadori:start` が作業を始めずに止まります。

## AI がしないこと

実査、棚卸立会、確認状の発送と回収、経営者への質問は人が行います。その記録を資料として取り込めば、調書で使います。
