# 開発する人へ

## 構成

```
tadori/
├─ .claude-plugin/marketplace.json
└─ plugins/tadori/
   ├─ .claude-plugin/plugin.json
   ├─ skills/
   │  ├─ start/              利用者が使う唯一の入口
   │  ├─ new-engagement/ intake/ plan/ run/ request-mail/ schedule/ finalize/
   │  └─ deliverables/ review-rubric/ audit-procedures/ client-documents/
   ├─ agents/                executor, reviewer, fixer, skeptic, requester, intake
   ├─ hooks/                 書込ガード、メール宛先ガード、作業ログ
   ├─ scripts/               状態判定、突合、MUS、仕訳テスト抽出、受領資料の登録と照合、依頼キュー、集計
   ├─ workflows/             Claude Code の Workflow ツールで run を回すスクリプト（判断は state.py）
   └─ templates/             案件設定、依頼メール文面、案件フォルダの説明
```

start 以外のスキルはメニューに出さず（`user-invocable: false`）、start から呼び出します。

「次にやること」（A〜H）、レビューループの判断（合格・打ち切り・修正に戻す）、調書の状態の移り変わり、予算の数え方は `scripts/state.py` が決めます。スキルの文章は、どのコマンドをいつ呼ぶかだけを書きます。判断を変えるときは state.py とテストを直してください。

## 確認

```bash
claude plugin validate plugins/tadori
python3 -m unittest discover -s tests
```

ローカルで試す：

```bash
claude --plugin-dir plugins/tadori
```

## 変更の流れ

main への変更は @monkeikawashima の承認が必要です。ブランチを切ってプルリクエストを出してください。

## 評価セット

誤謬を仕込んだ過去案件で検出率を測ります。実在の社名や数値が入るので、このリポジトリには置かず、非公開の場所で管理します。
