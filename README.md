# tadori

会計監査の手続・調書のレビュー・資料の依頼を、Claude が並列で進めるプラグインです。
人が決めるのは **計画の承認** と **最終査閲** の2回だけです。

> 監査意見の表明と調書の査閲は監査人の責任で、tadori はそれを代わりません。

<br>

## はじめかた

GitHub のアカウントは要りません。

1. [Claude デスクトップアプリ](https://claude.com/download)を入れてログイン
2. **設定** → **プラグイン** を開く
3. マーケットプレイスの追加を開き、**リポジトリから追加** を選んで `monkeikawashima/tadori` と入力
4. 一覧に出た **tadori** をインストール

tadori は Cowork で動きます。通常のチャットでは使えません。
最新版にするときは、同じ画面でこのマーケットプレイスを更新します。

資料依頼をメールで出すなら、設定のコネクタで Gmail か Outlook も接続しておきます。

<br>

## 使い方

Cowork で作業用のフォルダを開き、こう送ります。

```
/tadori:start
```

あとは tadori が次にやることを判断し、必要なことだけ質問します。

1. 案件フォルダを作る（クライアント名と決算期を聞かれます）
2. 試算表と仕訳帳を渡す
3. **監査計画を承認する** ← あなた
4. 手続・レビュー・修正を自動で繰り返す。足りない資料は依頼メールの下書きを作る
5. 資料が届いたらフォルダに置いて、もう一度 `/tadori:start`
6. **最終査閲** ← あなた

途中で「どこまで進んだ？」と聞けば、進み具合だけを答えます。
